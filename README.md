# Guía personal WoW Forever

Guía de profesiones 1-300, clases, talentos, nivelado, mazmorras, recetas, reputaciones, farmeo y mapas para la Horda en World of Warcraft: Forever.

Página: https://remiun.github.io/guia-personal-wow-forever/

Se genera cada día desde el proyecto local. Datos de Wowhead Forever y del cliente del juego; mapas e iconos de Wowhead/Blizzard.

**4-11-2026:** la web lleva un parche a mano con los cambios del lanzamiento (avisos en las builds, raciales finales y novedades). Para pasarlo al proyecto local antes de regenerar, ver [notas/CAMBIOS-LANZAMIENTO.md](notas/CAMBIOS-LANZAMIENTO.md).
